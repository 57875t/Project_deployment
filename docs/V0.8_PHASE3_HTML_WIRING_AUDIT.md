# QR Desk v0.8 — Phase 3 K线主体 HTML 接线审计

## 1. Preview

目标：让 HTML 直接消费 v0.8 网关的交易时段、质量、前收涨跌和末根 K 线涨跌字段，并把“已完成 K 线”与“独立实时报价”严格分开。

不可触碰边界：

- 真实通道必须明确 `syntheticBars = 0`；
- `quality.verdict = FAIL` 时禁止绘图；
- Provider 失败时不得自动生成模拟 K 线；
- 模拟模式只能由用户手动选择，并继续明确标注；
- 最后一根已完成 K 线收盘价不得冒充逐笔或独立实时报价；
- GLM 只允许读取通过真实 PASS 门禁的数据。

## 2. Execute

已完成：

- 接入 `quality`、`marketSession`、`quote.change/changePercent`、`quote.barChange/barChangePercent`；
- 新增交易时段、网关质量、清洗计数和合成数据卡片；
- “较前收涨跌”和“末根 K 线涨跌”分开显示；
- 网关只返回最后完成 K 线收盘时，实时状态显示为不可用，不冒充独立报价；
- 前端优先采用网关交易所日历状态；
- `syntheticBars != 0` 时立即拒绝真实响应；
- 自动/真实优先模式失败后只显示可信真实快照或不可用；不再自动切换模拟；
- Provider 时间戳若仍为 `assumed`，本地门禁降级，不能标记 LIVE PASS；
- 校准模拟仍保留为独立、手动模式。

## 3. Nitpick

本轮发现并关闭：

1. 后端 `quote.lastPrice` 当前等于最后已完成 K 线收盘，不是独立实时报价。前端已按 `last-completed-bar-close` 处理。
2. 原页面把区间首尾变化当作主涨跌，容易与交易软件“较前收涨跌”混淆。现已拆分。
3. 原自动模式在真实源失败后可能生成模拟线。现已改为 fail closed。
4. 原真实门禁没有强制 `syntheticBars=0`。现已强制。
5. 原页面主要依靠本地推算质量，没有完整展示网关质量计数。现已接线。
6. `provider-start-assumed` 尚未完成真实样本核验，现会进入 DEGRADED，而不是 PASS。

## 4. Review

### PASS

- JavaScript 语法检查通过；
- HTML ID 无重复；
- 所有 `elements.*` 引用均找到对应 DOM ID；
- 页面无 `127.0.0.1:8787` 遗留；
- 浏览器运行无 page error / console error；
- 16 项内置确定性测试全部通过；
- 自动模式失败关闭测试通过；
- synthetic contamination 门禁测试通过；
- 网关 v0.8 字段接线测试通过。

### OPEN

- 未连接授权行情供应商，无法做真实延迟验收；
- Provider bar-start/bar-end 仍需用真实响应核对；
- 后端尚未接入独立 quote feed，因此“实时状态”不会展示逐笔价格；
- 复权、拆股、分红以及双源容差仍待后续阶段；
- 历史指定日期接口仍未实现。

## 5. Acceptance

当前结论：**PHASE 3 DETERMINISTIC PASS / LIVE BLOCKED**。

页面和数据契约接线已通过离线确定性验收，但在授权 Provider、真实 entitlement、真实延迟与参考终端对账完成前，不宣称实时行情 LIVE PASS。
