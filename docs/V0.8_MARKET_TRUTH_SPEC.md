# QR Desk v0.8.0 — Market Truth Engine

## Objective

Move the Market Lab from “a chart that looks plausible” to a truth-gated K-line system that can approach the live market only by improving source quality, timestamps, session handling, latency, aggregation, and reconciliation.

“Calibration” never means fabricating a real candle. Simulation remains a separate mode.

## Data layers

1. **Authorized provider layer**
   - REST for historical backfill, reconnect repair, and snapshots.
   - WebSocket when the gateway explicitly advertises the capability.
2. **Closed-bar ledger**
   - Stores only validated closed OHLCV bars.
   - A forming bar is kept separate and may never overwrite a historical close.
3. **Quote layer**
   - Last trade / quote is independent from the last closed candle.
4. **Reference layer**
   - Public Yahoo/Eastmoney responses may be displayed only as reference validation.
   - They cannot pass the real-data gate, enter the trusted snapshot cache, or unlock prediction.
5. **Simulation layer**
   - Clearly labeled and isolated from all real fields.

## Required v0.8 provenance

A preferred gateway response should expose:

- provider and feed;
- entitlement and recency;
- transport (`rest` or `websocket`);
- provider timestamp and fetch timestamp;
- quote timestamp and bar timestamp;
- delay seconds;
- bar state (`closed`, `forming`, or `partial`);
- native interval and `aggregatedFrom` when applicable;
- adjustment mode;
- session / exchange status;
- request ID, warnings, and provider attempts.

## Truth score

The HTML calculates a visible 0–100 score from:

- authorized source;
- validation status and quality score;
- unexpected gaps, duplicate timestamps, and OHLC invariants;
- measured latency relative to the interval;
- quote-to-last-closed-bar divergence;
- closed/forming bar state.

The score is diagnostic. It never upgrades an untrusted source into a real source.

## Rise and amplitude metrics

- **Open → latest rise**: `(latest usable price - current session open) / session open`.
- **Intraday amplitude**: `(session high - session low) / previous close`, with session open used only when previous close is unavailable.
- **Quote → closed-bar delta**: `(latest quote - last closed bar close) / last closed bar close`.

These values describe observed movement; they are not forecasts or trade instructions.

## Stream contract

The page attempts WebSocket only when `/v1/market/health` advertises a stream capability. Suggested endpoint:

`wss://<gateway>/v1/market/stream?instrument=<code>&symbol=<symbol>&interval=<interval>`

Supported messages:

- quote/trade: latest price and timestamp;
- bar/aggregate: OHLCV plus closed/forming state;
- heartbeat.

Invalid stream bars are discarded. On disconnect, the page falls back to REST and requires backfill/reconciliation.

## Hard boundaries

- HTTPS/WSS only.
- No provider keys in the HTML.
- No trading or broker-account operations.
- No fake current-day candle on weekends, holidays, or closed sessions.
- No public reference source labeled real.
- No forming candle persisted as a closed candle.
